# Eksperimen SML Nana-Selviana

Repository ini berisi proyek eksperimentasi data untuk Kriteria 1 submission Membangun Sistem Machine Learning (MSML).

## Struktur Repository
- `namadataset_raw/`: Dataset mentah (`breast_cancer_raw.csv`).
- `preprocessing/`: Notebook eksperimen (`Eksperimen_Nana-Selviana.ipynb`) dan dataset hasil preprocessing (`namadataset_preprocessing.csv`).
